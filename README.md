# Reibar Keyword Research UI

Runs on **port 5173**. Not part of the Python SEO API repo.

1. Copy `.env.example` to `.env` if needed.
2. Set `VITE_API_TOKEN` to the same Bearer JWT you use in Swagger.
3. Set `VITE_API_BASE_URL` to your current ngrok host + `/api/v1`.
4. `npm install` then `npm run dev`
5. Open http://localhost:5173
